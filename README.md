# PayEcho

PayEcho speaks when Google Pay sends a notification saying money was received.

## Install and use

1. Copy `PayEcho.apk` to your Android phone and install it. If asked, allow
   installs from the app you used to open the file.
2. Open PayEcho and tap **Grant notification access**.
3. In Android Settings, allow notification access for PayEcho, then return to
   the app.
4. Leave **Speak Google Pay credit alerts** turned on.
5. Tap **Test voice alert** to check that speech works.

PayEcho needs Android 8.0 or newer. It reads matching Google Pay notifications
on your phone to detect received-payment alerts. It does not verify payments
with your bank. Notification wording can vary, so check that alerts work with
your Google Pay notifications. iPhone is not supported.
